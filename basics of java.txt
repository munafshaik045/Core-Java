What is java?
Ans: Java is a high-level, object-oriented programming language used to develop software applications, websites, and mobile applications.
->It is simple, secure, and platform-independent, which means Java programs can run on different operating systems without changing the code.

Why was Java created?
1991- Green Project- James Gosling and a small team at Sun Microsystems started exploring software for consumer devices.
1991 – Named "Oak"- The new language was named after an oak tree outside Gosling's office.
1992 – Star7 Demo- A handheld prototype called Star7 demonstrated Oak's capabilities on custom hardware.
1995 – Renamed Java- Oak was renamed Java because the name Oak was already trademarked.
1996 – JDK 1.0- First official release of Java (JDK 1.0).

The Problem
Devices used different chips and operating systems.
C/C++ programs had to be recompiled — often rewritten — for each device.
The Idea: Write Once, Run Anywhere (WORA)
Java introduced platform independence.
A Java program can be written once and run on different platforms without rewriting the code for each platform.

Java Evolution
1995 – Java 1.0
Java was officially introduced.
It introduced the principle "Write Once, Run Anywhere" (WORA).
It provided platform independence through the Java Virtual Machine (JVM).

1998 – Java 2 (Java 1.2)
Introduced the Collections Framework.
Improved graphical user interface development using Swing.
Strengthened Java for enterprise applications.

2004 – Java 5
Introduced Generics, Annotations, and Enumerations.
Added enhanced for-loops.
Made Java programming more efficient and readable.

2006 – Java 6
Improved performance and stability.
Enhanced web services support.
Open-source development of Java gained momentum.

2011 – Java 7
Introduced try-with-resources.
Added the diamond operator.
Improved exception handling and file operations.

2014 – Java 8
Introduced Lambda Expressions.
Added the Stream API.
Introduced functional programming features.
